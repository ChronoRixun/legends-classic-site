# Legends Classic - project site

The landing page for [Legends Classic](https://github.com/ChronoRixun/legends-classic), published with GitHub Pages
from this repository's `main` branch (root). `index.html` is a single self-contained page: no build step, no external
scripts or fonts.

## Images

`img/banner.png` and the gallery images `img/shot-NN.jpg` and `img/online-NN.jpg` (1600x900 unless the page's
`width`/`height` say otherwise, with an 800-wide `-800.jpg` copy each, every file under 400 KB) are referenced by the
page. Online screens captured in both aspect ratios also have a 4:3 `img/online-NN-4x3.jpg` (1200x900), linked from
the caption. The full-resolution originals stay out of
this repository. Rules for this repository:

- screenshots are in-game captures of a player's own Legends Classic build only, captioned as such;
- no official logos, box art, key art, cutscene stills or music;
- nothing from the games' files is committed here - the code repository's content guard rules still apply in spirit.

## Updating

Edit `index.html` and push to `main`; Pages redeploys in about a minute. Lines marked `<!-- release round: update -->`
are refreshed with each release.
